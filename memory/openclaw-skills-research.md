## 技能安装方法

### 通过 ClawHub

```bash
# ClawHub CLI (推荐方式)
npx clawhub@latest install <skill-slug>

# 或者使用 ClawHub 网站
# 1. 访问 https://clawhub.com
# 2. 搜索技能
# 3. 点击安装按钮
```

### 通过 GitHub

```bash
# 直接 clone技能仓库
git clone https://github.com/openclaw/skills/<skill-name>

# 或者使用 Clawdbot 技能
clawdbot install <skill-slug>
```

### 手动安装

```bash
# 1. 创建技能目录
mkdir -p ~/.openclaw/skills/<skill-name>

# 2. 下载 SKILL.md
curl -o ~/.openclaw/skills/<skill-name>/SKILL.md https://raw.githubusercontent.com/openclaw/skills/<skill-name>/main/SKILL.md

# 3. 编辑技能
vim ~/.openclaw/skills/<skill-name>/SKILL.md

# 4. 重启 OpenClaw
# 或者在 OpenClaw 中运行
# killall -HUP openclaw
# openclaw
```
