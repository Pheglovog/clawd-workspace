# CarLife Hardhat 升级评估 - 2026-02-09

## 当前状态

### 当前版本
- **Hardhat**: 2.28.4
- **@nomicfoundation/hardhat-toolbox**: 4.0.0

### 最新版本
- **Hardhat**: 3.1.7
- **@nomicfoundation/hardhat-toolbox**: 6.1.0

## 版本差异分析

### 主要版本变化（2.x → 3.x）

这是一个跨大版本的升级，从 2.28.4 升级到 3.1.7，包含了重大变更。

### 主要变化

#### 1. 任务库从 Hardhat 生态系统中分离
- Hardhat 3.x 引入了新的任务库系统
- 需要重新安装任务库（例如：`hardhat-deploy`）
- 现有的任务脚本可能需要调整

#### 2. Ethers.js v6 升级
- Hardhat 3.x 使用 ethers.js v6
- v5 API 与 v6 有一些不兼容的地方
- 主要变化：
  - `ethers.utils` 重命名为 `ethers`
  - 某些方法签名变化
  - BigNumber 处理变化

#### 3. 网络配置变化
- `networks` 配置需要更新
- 某些 RPC 链接配置需要调整
- `gasPrice` 配置方式变化

#### 4. 插件系统重构
- 插件 API 有重大变化
- 某些插件可能不兼容

### 兼容性风险评估

#### 高风险
1. **ethers.js v5 → v6 升级**
   - 许多代码需要更新
   - BigNumber 处理方式变化
   - 可能导致交易失败

2. **任务库分离**
   - 需要重新安装和配置任务库
   - 现有脚本可能需要调整

3. **网络配置**
   - 需要更新网络配置
   - 可能导致部署脚本失败

#### 中风险
1. **插件兼容性**
   - 某些插件可能不支持 Hardhat 3.x
   - 需要等待插件更新或寻找替代品

2. **测试运行器**
   - 测试代码可能需要调整
   - 某些测试工具可能不支持新版本

#### 低风险
1. **Solidity 编译器**
   - Solidity 版本通常向后兼容
   - 智能合约代码不需要修改

2. **Gas 估算**
   - Gas 估算功能基本保持一致

## 测试检查清单

在升级之前，建议先在测试环境中进行以下检查：

1. **网络配置检查**
   ```bash
   # 检查当前网络配置是否兼容
   npx hardhat node
   # 测试部署到本地节点
   npx hardhat run scripts/deploy.js --network localhost
   ```

2. **编译检查**
   ```bash
   # 检查智能合约是否可以正常编译
   npx hardhat compile
   ```

3. **测试检查**
   ```bash
   # 运行测试脚本，检查是否所有测试都通过
   npx hardhat test
   ```

4. **部署脚本检查**
   ```bash
   # 测试部署脚本是否可以正常工作
   npx hardhat run scripts/deploy.js --network hardhat
   ```

## 升级建议

### 选项 1：不升级（推荐短期）
- **理由**: 跨大版本升级风险高，兼容性问题多
- **优势**: 稳定性高，无兼容性问题
- **劣势**: 无法使用新功能和 bug 修复
- **适用场景**: 项目稳定，不需要新功能

### 选项 2：升级到 Hardhat 3.1.7（推荐长期）
- **理由**: 使用最新版本，获得新功能和 bug 修复
- **优势**: 长期支持，新功能
- **劣势**: 需要更新代码，兼容性问题
- **适用场景**: 项目需要新功能，可以接受短期不稳定
- **前提条件**:
  1. 有完整的测试覆盖
  2. 可以在测试环境中验证
  3. 有足够的时间进行测试和修复

### 选项 3：升级到 Hardhat 2.19.0（推荐中期）
- **理由**: 2.19.0 是 2.x 系列的最新稳定版本
- **优势**: 兼容性好，风险低
- **劣势**: 无法使用 3.x 的新功能
- **适用场景**: 项目需要更新但风险要低

## 升级步骤（如果决定升级）

1. **备份数据**
   ```bash
   # 备份重要数据
   cp -r .git .git.backup
   ```

2. **更新依赖**
   ```bash
   # 更新到 Hardhat 3.1.7
   npm install hardhat@latest @nomicfoundation/hardhat-toolbox@latest
   ```

3. **更新代码**
   - 更新 ethers.js v5 到 v6 的代码
   - 更新网络配置
   - 更新任务库配置

4. **测试**
   - 运行测试脚本
   - 测试部署脚本
   - 测试所有功能

5. **部署**
   - 在测试网部署
   - 验证所有功能
   - 在主网部署

## 回滚计划

```bash
# 回滚到 Hardhat 2.28.4
npm install hardhat@2.28.4 @nomicfoundation/hardhat-toolbox@4.0.0
```

## 总结

**短期建议**: 不升级，继续使用 Hardhat 2.28.4
**中期建议**: 升级到 Hardhat 2.19.0（2.x 系列最新）
**长期建议**: 升级到 Hardhat 3.1.7（3.x 系列最新），但需要充分测试

**风险等级**: 高
